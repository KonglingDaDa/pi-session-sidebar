# 发布假设

| 决定 | 理由 | 代价 / 复核时机 |
| --- | --- | --- |
| 仓库名 pi-session-sidebar，MIT 许可证 | 独立 Pi 侧栏包，名字直接说明用途，宽松复用 | 后续发布策略变化时复核 |
| 范围为时间线、下一步预测与回复后建议 | 完整保留用户讨论的侧栏能力 | 发送前技能推荐属于另一功能，不在本包 |
| 默认 google/gemini-2.5-flash；可配置任意兼容 Pi 模型 | 移除个人 provider 别名与网关依赖 | 更换模型需验证结构化 JSON 与思考档位 |
| Jev 默认官方 HTTPS，支持回环网关 | 可独立安装，无个人服务依赖 | 不接受任意公网中转；需要新增主机时单独设计 |
| 保留 v1 EventBus 与旧缓存名称 | 兼容既有会话缓存 | 不要同时加载旧本机插件与新包 |
| 以 Pi / pi-tui 1.0.2 验证 | 全屏分栏与选区依赖内部方法 | 升级 Pi 后重新跑真实渲染器与加载器测试 |
| 独立目录发布，本机 pi-local 不迁移或改设置 | 保留用户现有运行配置和未提交改动 | 后续日常维护需明确采用哪一目录 |
| 不发布真实会话、截图、校准数据、凭据及本机配置 | GitHub 内容只由显式选入的代码和文档组成 | 每次发布按包内容检查 |
